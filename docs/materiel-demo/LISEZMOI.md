## Parcours conseillé (compte `enseignant@demo.nexora.test`)

1. **Atelier IA** → *Le cours à résumer* → *Importer un fichier* → `cours-cellule-eucaryote.pdf`.
2. *Nouvelle fiche* : titre « La cellule eucaryote », cours « Biologie cellulaire ».
3. Niveau *Standard*, garder *Ajouter une illustration générée* → **Lancer l’IA**. La page affiche la progression ; la fiche se remplit (résumé, points clés, glossaire) en 20 à 60 secondes.
4. Sur la fiche : **Illustrations** → *Importer une image* → `schema-cellule.png`, avec une description (obligatoire pour l’accessibilité).
5. Relire, cocher la relecture, **Publier**. Côté étudiant (`etudiant@demo.nexora.test`) : la fiche apparaît, avec le **Quiz d’entraînement IA** et les cartes de révision.

Si le quota gratuit de Gemini est atteint, le modèle local Ollama prend le relais ; si celui de Hugging Face l’est, importer le schéma correspondant.
